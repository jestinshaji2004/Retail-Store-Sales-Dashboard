# Retail Store Sales Dashboard

An interactive Excel dashboard that analyses retail store sales data to highlight revenue trends, top-selling products, and overall business performance.

## Dashboard Preview
![Dashboard](Screenshot%202026-06-10%20094449.png)

## Project Overview
This project cleans and analyses retail sales data and presents the results in a single-page dashboard for quick decision-making.

## Key Features
- Total sales, revenue, and profit summary
- Sales trends over time
- Top-performing products and categories
- Interactive filters (slicers)

## Tools Used
- Microsoft Excel (Pivot Tables, Charts, Slicers)
