# 🛍️ Retail Store Sales Dashboard | Excel

An interactive **Retail Store Sales Dashboard built using Microsoft Excel** to analyze sales performance, profitability, payment methods, product categories, and regional trends.

This project transforms raw retail sales data into meaningful business insights through KPI cards, interactive charts, and slicers.

## 📊 Dashboard Preview

![Retail Store Sales Dashboard](Screenshot%202026-06-10%20094449.png)

## 🎯 Project Objectives

- 📈 Monitor overall sales and profitability.
- 🛒 Analyze total orders and quantity sold.
- 💳 Compare profit across different payment methods.
- 🏷️ Evaluate category-wise and sub-category-wise profitability.
- 🌎 Identify differences in profit across states.
- 📅 Understand monthly and yearly profit trends.
- 🔎 Explore sales data using interactive filters.

## 🛠️ Tools & Techniques

- **Microsoft Excel**
- Pivot Tables and Pivot Charts

- Interactive Slicers
- Data Cleaning and Preparation
- Sales Analysis and Data Visualization

## 🔍 Analysis Included

### 💳 Payment Method Analysis
Compares profitability across payment methods such as COD, credit card, debit card, EMI, and UPI.

### 🏷️ Category and Sub-Category Analysis
Explores how Electronics, Furniture, and Office Supplies contribute to overall profit.

### 📅 Monthly and Yearly Trends
Visualizes changes in profitability over time to help identify trends and fluctuations.

### 🌎 State-Wise Profit Analysis
Compares profit across states to highlight regional differences in business performance.

### 🎛️ Interactive Filtering
Uses slicers to explore the dashboard by category, state, year, and other available fields.

## 💡 Business Value

This dashboard provides a consolidated view of retail performance, helping users explore revenue, profitability, product categories, payment methods, and regional trends in one place.

It demonstrates how Excel-based analytics can make business data easier to understand and support informed decision-making.
